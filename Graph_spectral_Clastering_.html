Мода λ₂ рухає вершини по горизонталі, λ₃ — по вертикалі, далі по черзі. Частота ω ∝ √λ. За фазою: зелений — у фазі з найрухливішою по горизонталі вершиною, червоний/синій — у фазі/протифазі по вертикалі; білі вершини нерухомі. Початково ввімкнено моди, що використовує кластеризація (v₂…vk).

Лапласіан L = D − A та власні числа


Теорія

Ідея. Для графа з матрицею суміжності A та діагональною матрицею степенів D лапласіан L = D − A симетричний і напівпозитивний: xᵀLx = Σ(i,j)∈E(xᵢ−xⱼ)². Тому власні числа 0 = λ₁ ≤ λ₂ ≤ … ≤ λₙ, а кратність нуля дорівнює кількості компонент зв’язності.


Вектор Фідлера. Мінімізація xᵀLx при x ⟂ 1, ‖x‖=1 дає другий власний вектор v₂: вершини зі схожими координатами сильно зв’язані, а розріз за знаком v₂ наближує мінімальний нормалізований розріз (релаксація задачі RatioCut).


Для k кластерів беруть власні вектори v₂…vk (тобто k−1 штук: 1D для k=2, 2D для k=3, 3D для k=4). Рядок (v₂(i),…,vk(i)) — координата вершини i, і в цьому просторі застосовують k-means.


Eigengap. Хорошу кількість кластерів часто вказує найбільший стрибок λk+1 − λk.


k-means. Повторюємо: (1) призначити кожну точку найближчому центру; (2) перенести центр у середнє своїх точок; до стабілізації призначень. Результат залежить від початкових центрів. Кластери на графі розсунуто лише візуально.


Моди коливань. Якщо вершини — маси, а ребра — пружини, рух графа розкладається на гармонічні моди: власний вектор vj задає форму, а частота ωj = √λj. Моди з малим λ рухають великі групи вершин разом (їхні знаки показують розріз на кластери), а моди з великим λ — сусідів у протифазі.


Нормований лапласіан. Lrw = D⁻¹L (власні вектори L v = λ D v) враховує степені вершин: при цьому розріз балансується за об’ємом, а не за кількістю вершин, і k-means часто краще працює на графах із хабами та на карате. Перемикач «нормований» порівнює обидва варіанти.
